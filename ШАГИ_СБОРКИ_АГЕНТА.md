# Сборка агента VK KIE — по шагам

Ниже упрощённая рабочая дорожная карта строго под ваш сценарий: **Python + Cursor + KIE AI**.

---

## Шаг 1. Контракт входа (сделано)

Файлы:

- `contracts/agent-input-template.json`
- `contracts/agent-input-template.md`

Что это даёт:

- один и тот же формат входа для Cursor и для будущего Python-скрипта;
- меньше хаоса в постановке задач агенту;
- меньше риска, что ИИ начнёт додумывать факты.

## Шаг 4. Решение по визуалу (сделано)

Правило по умолчанию:

- `Nano Banana Pro` — чек-лист, инфографика, обложка, комикс, карусель;
- `Veo 3` — короткое вертикальное видео 10–30 секунд;
- если много текста и точных формулировок, сначала статика, потом видео только при необходимости.

- `docs/workflows/visual-decision.md`

## Шаг 5. Python-реализация

Первая версия скрипта:

1. Читать JSON из `contracts/agent-input-template.json`
2. Формировать текстовый запрос
3. Печатать черновик поста
4. После подтверждения формировать промпт для KIE
5. Позже — подключить прямой вызов API

Уже создан первый файл:

- `run_agent.py`

Что он делает сейчас:

- читает входной JSON;
- собирает итоговый user message из файлов проекта;
- формирует payload для `claude-sonnet-4-6`;
- сохраняет результаты в папку `output/`.

## Постоянное правило качества текста

Для всех новых текстов зафиксирован обязательный алгоритм:

1. Проверка на факты
2. Проверка на соответствие VK
3. Только потом финальная выдача

Файл:

- `docs/workflows/text-double-check.md`
