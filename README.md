# VK SMM — кабинет агентства для ВКонтакте с ИИ

Веб-приложение для SMM-агентств и специалистов: ведение клиентов во **ВКонтакте** с помощью ИИ.

**Для кого:** владельцы SMM-агентств и фрилансеры, которые ведут несколько групп ВК.  
**Проблема:** рутина «тема → текст → картинка/видео → согласование → публикация».  
**Решение:** кабинет с отдельным контекстом на каждый канал (клиент), генерацией контента и публикацией в ВК.

Выпускной проект курса по автоматизации бизнес-задач с помощью ИИ.

---

## Что умеет

- Несколько **каналов** (клиентов ВК) в одном аккаунте
- База знаний, рубрики, визуальный стиль и референсы **на канал**
- ИИ-маркетолог: бриф и правила для агентов
- Контент-план на период + согласование клиентом по ссылке
- Генерация поста: **текст + картинка и/или видео**
- Календарь, предпросмотр, публикация и автопубликация в ВК
- Месячный отчёт клиенту (Excel / PDF)
- Тарифы и **тестовая форма оплаты** (заглушка: деньги не списываются)

### Провайдеры ИИ

| Задача | Основной | Резерв |
|--------|----------|--------|
| Текст | KIE | VseGPT |
| Картинка | VseGPT | KIE (если нет ответа ~3 мин) |
| Видео | Kling (KIE) | — |

## Быстрый старт

### Шаг 1. Клонировать репозиторий

```bash
git clone https://github.com/ActiveProfi/vk-smm.git
cd vk-smm
```

### Шаг 2. Установить зависимости

```powershell
py -3 -m pip install -r requirements.txt
```

### Шаг 3. Настроить ключи

1. Скопируй `.env.example` → `.env`
2. Заполни API-ключи (KIE, VseGPT, токены ВК и т.д.)
3. **Не публикуй** `.env` и файлы с токенами

### Шаг 4. Запустить веб-кабинет

```powershell
py -3 run_webapp.py
```

Открой в браузере: [http://127.0.0.1:5050](http://127.0.0.1:5050)

Подробнее: [`КАК_ЗАПУСКАТЬ_ВЕБ.md`](./КАК_ЗАПУСКАТЬ_ВЕБ.md)

## Важно про безопасность

### Что уже сделано в кабинете

- Пароли хранятся только как хэш (bcrypt), минимум **8 символов**
- Токены ВК и VK Реклама в базе — **зашифрованы** (`enc:…`, ключ `APP_ENCRYPTION_KEY` / `FLASK_SECRET_KEY`)
- Лимит попыток входа: **7 ошибок за 15 минут** (по логину / IP)
- При регистрации — согласие с [политикой ПДн](/auth/privacy)
- Журнал действий владельца: **Журнал** в меню (`/auth/security-log`)
- Баннер, если включён `WEBAPP_DEV_SKIP_AUTH=1` (вход без логина)

### Чек-лист перед боевым сервером

1. В `.env` задать длинный `FLASK_SECRET_KEY` (или `SECRET_KEY`)
2. Задать отдельный `APP_ENCRYPTION_KEY` и **не менять его** после запуска (иначе старые токены не расшифруются)
3. Поставить `WEBAPP_DEV_SKIP_AUTH=0` (или удалить строку)
4. На HTTPS: `SESSION_COOKIE_SECURE=1`
5. Не коммитить `.env`, `webapp/.secret_key`, `webapp/site.db`
6. API-ключи и токены ВК — только в `.env` или в настройках канала (в БД уже шифруются)

Форма оплаты в кабинете пока **тестовая**: карта не сохраняется, деньги не списываются.
