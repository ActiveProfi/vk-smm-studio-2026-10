## Служебные тесты (PowerShell)

Папка `tools/`: сценарии для проверки доступов, читают **только** `.env` в корне проекта.

- `tools/get_gigachat_token.ps1` — access token GigaChat
- `tools/test_gigachat_models.ps1` — список моделей GigaChat
- `tools/test_anthropic_key.ps1` — тест `Anthropic`
- `tools/get_yandex_oauth_token.ps1` — обмен **свежего** `code` на токен (секреты из `.env`)
- `tools/run_vk_month_generation.py` — подготовка/запуск месячной генерации VK-черновиков
- `tools/vk_publish_once.ps1` — один запуск публикации VK для планировщика Windows
- `tools/vk_playwright_publish_once.ps1` — один строгий запуск публикации VK через Playwright
- `docs/workflows/vk-article-publish.md` — шаги публикации статьи VK и обложки

Пример запуска из корня проекта:

```text
powershell -ExecutionPolicy Bypass -File ".\tools\test_anthropic_key.ps1"
```

Для Yandex с **новым** кодом:

```text
powershell -ExecutionPolicy Bypass -File ".\tools\get_yandex_oauth_token.ps1" -Code "ВСТАВЬ_КОД"
```

Для подготовки месячных VK-входов без отправки в KIE:

```text
py -3 tools/run_vk_month_generation.py
```

Для одного запуска публикации по расписанию:

```text
powershell -ExecutionPolicy Bypass -File ".\tools\vk_publish_once.ps1"
```

Для одного строгого запуска публикации через Playwright:

```text
powershell -ExecutionPolicy Bypass -File ".\tools\vk_playwright_publish_once.ps1"
```

## Путь входа в VK ID для автопостинга

Чтобы не ходить по кругу через старые `dev.vk.com` приложения и `Mini Apps`:

1. Войти в сервис авторизации `VK ID`.
2. Использовать профиль бизнеса в `VK Бизнес ID`.
3. Открыть кабинет приложений `VK ID`.
4. Выбрать уже созданное приложение для автопостинга.

Важно: наше приложение нужно не для интерфейса внутри VK, а для авторизации и получения доступа к `VK API` для автопостинга.

## Получение VK_USER_TOKEN

Рабочий способ, который использовали в проекте:

1. Открыть сервис `VK Host`.
2. Выбрать приложение, у которого в окне разрешений VK явно есть доступы к фото/стене/группам.
3. Получить пользовательский токен администратора сообщества с правами для публикации.
4. Сохранить токен только в `.env`:

```text
VK_USER_TOKEN=...
```

Секретный токен в документацию, чат и код не вставлять.

Важно: токен через `VK Connect` без выбора прав был проверен, но не подошёл для картинок:
`photos.getWallUploadServer` вернул ошибку `15` — не хватает scope.
