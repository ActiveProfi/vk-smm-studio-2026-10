Как подключить сообщество (актуально на 2026)

Способ 1 — ключ сообщества (проще всего, без dev.vk.com):

  1. Откройте ваше сообщество ВК.
  2. Управление → Дополнительно → Работа с API.
  3. Вкладка Ключи доступа → Создать ключ.
  4. Отметьте права: Управление сообществом, Фото, Стена, Видео (что доступно в списке).
  5. Подтвердите в приложении ВК или по СМС → Показать → скопируйте ключ.
  6. Вставьте ключ в поле «VK API токен» ниже, ID группы — в соседнее поле.

Способ 2 — токен пользователя (если посты с картинкой/видео не публикуются):

  1. Старый способ через oauth.vk.com больше не актуален.
  2. Сейчас токен пользователя получают через VK ID для бизнеса (OAuth 2.1) или сервис вроде vkhost.github.io (приложение «VK Admin», права wall, photos, video, groups, offline).
  3. Токен нужно получить на этом же компьютере, где работает кабинет.

Официальная справка: ключ сообщества, ключ пользователя. Токен не публикуйте в чатах и постах.
