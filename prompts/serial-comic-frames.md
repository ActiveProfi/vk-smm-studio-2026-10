# Блок для сериала: описание кадров для комикса

Используй этот блок как дополнение к `prompts/serial.md`, когда нужен визуал через `Nano Banana Pro`.

## Что нужно вернуть

Опиши **3–4 кадра** для комикса так, чтобы их можно было отдать в KIE.

## Для каждого кадра укажи

1. Где происходит сцена
2. Что делает Алина
3. Какая у нее эмоция
4. Что происходит в кадре визуально
5. Нужен ли текст в кадре или лучше оставить его для ручного наложения

## Важные правила

- Для рубрики `serial` + юмор визуал тоже должен быть живым: легкие гэги, преувеличенные реакции, узнаваемая офисная абсурдность. Без грубости и без насмешки над бухгалтером.
- Алина должна выглядеть одинаково узнаваемо от кадра к кадру.
- Если серия в офисе — деловой стиль.
- Если серия вне офиса — одежда соответствует ситуации.
- Не перегружай кадры длинными русскими фразами.
- Лучше использовать короткие подписи, цифры, иконки, документы, экран, папки, переговорку, стол бухгалтера и другие понятные элементы.
- Смысловой текст в кадрах — только на русском языке.
- Не добавляй иностранные слова, латиницу, сторонние URL, иностранную валюту, знаки `$`, `€`, `£`, логотипы, эмодзи и посторонние декоративные символы в реплики, подписи и блоки.
- Если во входных данных указана «подпись внизу визуала» — добавь её маленьким текстом строго по центру внизу. Если не указана — не выдумывай сайт.
- Для VK указывай формат комикса явно: `1:1` или `4:5`. Для вертикального видео — `9:16`.

## Мини-формат ответа

```text
Кадр 1:
...

Кадр 2:
...

Кадр 3:
...
```
