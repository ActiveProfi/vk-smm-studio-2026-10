# User Prompt: `article_announcement`

Используй этот шаблон вместе с `prompts/base-system-kie.md`.

## Задача

Подготовь короткий VK-пост-анонс к статье.

## Требования к тону

- Тон: спокойный, полезный, без кликбейта.
- Пост должен объяснить, зачем читать статью.
- Не пересказывай всю статью в посте.
- Не обещай готовое решение для всех ситуаций.

## Оформление текста (UX)

- Пиши с учётом UX ленты VK: короткие абзацы, пустые строки между блоками, подзаголовки блоков отдельной строкой.
- Главный заголовок, подзаголовки и названия блоков/мыслей обязательно выделяй **жирным** через **двойные звёздочки** отдельной строкой. Остальной текст — обычный, без `#` и служебных пометок.
- Подробное правило — в `prompts/base-system-kie.md`, разделы «Оформление текста для VK (UX)» и «Чистый текст для копирования в VK».

## Структура поста

Собери текст по логике:

1. Короткий хук по проблеме.
2. Что читатель найдёт в статье.
3. 3-5 коротких тезисов.
4. Ссылка на статью или место для ссылки, если она ещё не опубликована.
5. Мягкий CTA: прочитать, сохранить, задать вопрос.

## Что нужно вернуть

1. Готовый пост-анонс для VK в финальном виде для моментальной публикации: чистый текст для копирования, без markdown и служебных комментариев. Сохранять в `output/*-post-draft.txt`.
2. Одной строкой: почему статья полезна читателю.
3. Рекомендацию: `image` или `video`.
4. Короткий промпт для KIE под выбранный визуал.
5. Что проверить перед публикацией.

- `post_type`: `{{post_type}}`

- `sources_note`: `{{sources_note}}`
- `tone`: `{{tone}}`
- `cta`: `{{cta}}`

## Ограничения по тексту

- Не выдумывай факты, ставки, сроки, лимиты и нормы закона.
- Если ссылка на статью ещё не дана, поставь нейтральный маркер: `[ссылка на статью]`.
- Для числовых примеров по умолчанию используй только ставку **22%**.
- Ориентируйся на пост до **2500 символов**.
- Не используй иностранные слова и латиницу без необходимости.
- Не добавляй технические комментарии, служебные пометки и пояснения для агента в готовый текст поста.

## Ограничения по визуалу VK

- По умолчанию выбирай `image`: пост-анонс лучше поддержать отдельной иллюстрацией, а не обложкой статьи.
- Не используй обложку статьи как единственный визуал поста, если нужен отдельный постовый визуал.
- Если отдельно делается обложка статьи (16:9), не пересказывай на ней содержание статьи.
- Для обложки статьи используй минимум текста: 1 сильный заголовок и 1 короткий подзаголовок или 1 короткий факт/число.
- Подробности и тезисы статьи оставляй в тексте, а не на обложке.
- Для изображения VK укажи формат явно:
  - лента: `4:5`;
  - карточка-анонс: `1:1`;
  - видео: `9:16`, только если это короткий анонс без длинного текста.
- Смысловой текст на изображении — только на русском языке.
- Не добавляй иностранные слова, латиницу, сторонние URL, иностранную валюту, знаки `$`, `€`, `£`, логотипы, эмодзи и лишние декоративные символы в заголовки, блоки и подписи.
- На картинке должен быть короткий нейтральный заголовок, а подробности оставь в тексте поста.
- Если во входных данных указана «подпись внизу визуала» — добавь её маленьким текстом строго по центру внизу. Если не указана — не выдумывай сайт и не добавляй чужой адрес.
