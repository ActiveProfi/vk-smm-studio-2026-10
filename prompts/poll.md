# User Prompt: `poll`

Используй этот шаблон вместе с `prompts/base-system-kie.md`.

## Задача

Подготовь пост для VK в формате вопроса или опроса по теме НДС.

## Важное ограничение

Если техническая публикация настоящего VK-опроса недоступна, сделай обычный VK-пост с вопросом и вариантами ответов. Такой пост должен быть понятен без встроенного опросника.

## Требования к тону

- Тон: дружелюбный, вовлекающий, профессиональный.
- Вопрос должен быть полезным, а не ради активности.
- Не провоцируй спор ради спора.
- После вариантов ответа дай короткое пояснение, почему тема важна.

## Оформление текста (UX)

- Пиши с учётом UX ленты VK: короткие абзацы, пустые строки между блоками, подзаголовки блоков отдельной строкой.
- Главный заголовок, подзаголовки и названия блоков/мыслей обязательно выделяй **жирным** через **двойные звёздочки** отдельной строкой. Остальной текст — обычный, без `#` и служебных пометок.
- Подробное правило — в `prompts/base-system-kie.md`, разделы «Оформление текста для VK (UX)» и «Чистый текст для копирования в VK».

## Структура поста

Собери текст по логике:

1. Короткая подводка.
2. Один главный вопрос.
3. 3-5 вариантов ответа.
4. Короткое пояснение, зачем это проверить.
5. Мягкий призыв написать ответ или ситуацию в комментариях.

## Что нужно вернуть

1. Готовый пост-опрос для VK в финальном виде для моментальной публикации: чистый текст для копирования, без markdown и служебных комментариев.
2. Одной строкой: какую реакцию или данные должен собрать пост.
3. Рекомендацию: `image` или `video`.
4. Короткий промпт для KIE под выбранный визуал.
5. Что проверить перед публикацией.

## Входные данные

- `post_type`: `{{post_type}}`
- `raw_materials`: `{{raw_materials}}`
- `sources_note`: `{{sources_note}}`
- `tone`: `{{tone}}`
- `cta`: `{{cta}}`
- `visual_intent`: `{{visual_intent}}`

## Ограничения по тексту

- Не выдумывай факты, ставки, сроки, лимиты и нормы закона.
- Если вопрос зависит от условий, не делай один вариант “правильным для всех”.
- Для числовых примеров по умолчанию используй только ставку **22%**.
- Ориентируйся на пост до **2500 символов**, потому что опрос должен читаться быстро.
- Не используй иностранные слова и латиницу без необходимости.
- Варианты ответа должны быть короткими и понятными.

## Ограничения по визуалу VK

- По умолчанию выбирай `image`: вопрос лучше поддержать простой карточкой.
- Если делается обложка статьи по опросной теме (16:9), не размещай на обложке весь опрос и варианты ответов.
- Для обложки статьи используй минимум текста: 1 сильный заголовок и 1 короткий подзаголовок или 1 короткий факт/число.
- Варианты ответов и подробности оставляй в тексте статьи.
- Для изображения VK укажи формат явно:
  - лента: `4:5`;
  - карточка-вопрос: `1:1`;
  - видео: `9:16`, только если это короткая сценка без длинного текста.
- Смысловой текст на изображении — только на русском языке.
- Не добавляй иностранные слова, латиницу, сторонние URL, иностранную валюту, знаки `$`, `€`, `£`, логотипы, эмодзи и лишние декоративные символы в заголовки, блоки и подписи.
- На картинке должен быть один короткий вопрос или нейтральный заголовок. Варианты ответов лучше оставить в тексте поста.
- Если во входных данных указана «подпись внизу визуала» — добавь её маленьким текстом строго по центру внизу. Если не указана — не выдумывай сайт и не добавляй чужой адрес.
