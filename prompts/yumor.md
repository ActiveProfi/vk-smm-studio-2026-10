# User Prompt: `yumor`

**Внимание:** рубрика объединена с `serial`. Для новых материалов используй:

- `prompts/serial.md`
- `prompts/serial-yumor-advanced-template.md`

Ниже — краткий режим «один юмористический пост без серии». Для сериала с крючками и мультиформатом — только advanced-шаблон.

Используй этот шаблон вместе с `prompts/base-system-kie.md`.

## Задача

Подготовь пост для VK в формате **легкого профессионального юмора** (одиночный пост, не сезон).

## Требования к тону

- Тон: дружелюбный, живой, профессиональный.
- Юмор допустим, но без кринжа, без грубости и без обесценивания бухгалтера.
- Даже в шутке сложная ситуация должна быть объяснена понятно для новичка.

## Оформление текста (UX)

- Пиши с учётом UX ленты VK: короткие абзацы, пустые строки между блоками, подзаголовки блоков отдельной строкой.
- Главный заголовок, подзаголовки и названия блоков/мыслей обязательно выделяй **жирным** через **двойные звёздочки** отдельной строкой. Остальной текст — обычный, без `#` и служебных пометок.
- Подробное правило — в `prompts/base-system-kie.md`, разделы «Оформление текста для VK (UX)» и «Чистый текст для копирования в VK».

## Формат

- Короткая сценка, абсурдная ситуация, диалог или наблюдение из практики.
- После шутки обязательно дай **серьезную полезную мысль** по НДС.
- В конце — вопрос подписчикам или короткий вовлекающий комментарий.

## Что нужно вернуть

1. Черновик поста для VK
2. Одной короткой строкой: где здесь практическая польза
3. Рекомендацию: `image` или `video`
4. Короткий промпт для KIE под выбранный визуал
5. Что проверить перед публикацией

## Входные данные

- `post_type`: `{{post_type}}`
- `raw_materials`: `{{raw_materials}}`
- `sources_note`: `{{sources_note}}`
- `tone`: `{{tone}}`
- `cta`: `{{cta}}`
- `visual_intent`: `{{visual_intent}}`

## Ограничения

- Не искажай факты ради шутки.
- Не превращай текст в стендап.
- Для числовых примеров по умолчанию используй только ставку **22%**.
- Если для шутки нужен визуал, лучше предлагай короткую статику или простой ролик.
- Ориентируйся на пост до **3000 символов**.
- Не используй иностранные слова и латиницу без необходимости.

## Ограничения по визуалу VK

- Для юмора можно выбрать `image` или `video`, но польза по НДС должна оставаться понятной.
- Если смысл держится на русском тексте в кадре, сначала выбирай `image` через `Nano Banana Pro`, а не прямое text-to-video.
- Если делается обложка статьи по юморной теме (16:9), она должна быть крючком, а не пересказом материала.
- Для обложки статьи используй минимум текста: 1 сильный заголовок и 1 короткий подзаголовок или 1 короткий факт/число.
- Полную суть, разбор и полезный вывод оставляй в тексте статьи.
- Для изображения VK укажи формат явно:
  - лента: `4:5`;
  - мем-карточка или сценка: `1:1`;
  - видео: `9:16`.
- Смысловой текст на изображении — только на русском языке.
- Не добавляй иностранные слова, латиницу, сторонние URL, иностранную валюту, знаки `$`, `€`, `£`, логотипы, эмодзи и лишние декоративные символы в заголовки, блоки и подписи.
- На картинке не должно быть грубости, унижения бухгалтера или длинных фраз.
- Если во входных данных указана «подпись внизу визуала» — добавь её маленьким текстом строго по центру внизу. Если не указана — не выдумывай сайт и не добавляй чужой адрес.
