# Контракт входа для агента VK KIE

Это единый шаблон, который вы будете давать агенту в Cursor или Python-скрипту.

## Поля

| Поле | Что писать |
| ----- | ---------- |
| `post_type` | `expert`, `razbor`, `case`, `calculation`, `law_review`, `checklist`, `poll`, `serial`, `yumor`, `article_announcement` |
| `raw_materials` | Ваши тезисы, цифры, цитаты, факты, выдержки |
| `sources_note` | Откуда взято: НК РФ, письмо ФНС, лекция, методичка |
| `tone` | Желаемый тон: спокойно, с иронией, строго, дружелюбно |
| `cta` | `yes` или `no` |
| `visual_intent` | `image`, `video`, `decide` |

## Пример

```json
{
  "post_type": "checklist",
  "raw_materials": [
    "ИП на УСН нужно проверить, возникает ли обязанность по НДС",
    "В примерах использовать только ставку 22%"
  ],
  "sources_note": "конспект интенсива + база фактов проекта",
  "tone": "спокойно, без паники",
  "cta": "yes",
  "visual_intent": "image"
}
```

## Важно

- Если факта нет в `raw_materials` или в `knowledge/nds-2026-facts.md`, агент не должен его додумывать.
- Для числовых примеров по умолчанию использовать только ставку **22%**.
- Ориентир по длине обычного VK-поста — до **4000 символов**.
- Для смыслового текста на изображениях использовать только русский язык.
- В смысловых блоках визуала не использовать иностранные слова, латиницу, иностранную валюту, знаки `$`, `€`, `£`, логотипы, эмодзи и лишние декоративные символы.
- В самом низу каждого визуала добавлять маленький адрес сайта `nds04ka.online`.
- Для VK-визуалов явно указывать формат: `4:5` для ленты, `1:1` для карточки/инфографики, `9:16` для видео.
- Для обложки статьи VK использовать отдельное правило: `16:9`, ориентир `1020x572 px`.
