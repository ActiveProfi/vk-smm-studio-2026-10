# Черновик обращения в поддержку VK

Куда писать: `devsupport@corp.vk.com`

Тема письма:

```text
Нужен доступ к VK API для автопубликации в сообщество: wall/photos/groups
```

Текст письма:

```text
Здравствуйте.

Нам нужен официальный способ получить пользовательский access token или иной разрешённый токен VK API для автопубликации материалов в наше сообщество.

Задача:
- публиковать записи в администрируемое сообщество;
- прикреплять к постам изображения/инфографику;
- запускать публикацию по расписанию из нашей системы.

Сообщество:
- ID сообщества: 227844577

Приложение:
- ID приложения: 54572210
- приложение создано в VK ID / сервисе авторизации

Какие методы VK API нужны:
- wall.post
- photos.getWallUploadServer
- photos.saveWallPhoto
- при необходимости video.save

Проверки:
- токен сообщества успешно вызывает groups.getById и wall.post для текстовой записи;
- photos.getWallUploadServer с токеном сообщества возвращает ошибку 27: method is unavailable with group auth;
- пользовательский токен, полученный через VK Host / VK Connect, возвращает ошибку 15: cannot be called with current scopes.

Нужны права/доступы:
- wall
- photos
- groups
- video, если возможно
- offline или другой официальный механизм долгосрочной серверной публикации/обновления токена

Подскажите, пожалуйста, какой сейчас официальный путь получить такой доступ для приложения и сообщества.
```

Важно: в письмо не вставлять секретные ключи, access token, refresh token, service key и protected key.
