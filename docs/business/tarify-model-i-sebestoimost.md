# Тарифы VK SMM: модель «функции + каналы» и себестоимость

Документ с расчётами для запуска продукта.  
**Статус:** предложение по модели продаж (в код пока не внедрялось).  
**Дата:** 28.07.2026

---

## 1. Идея модели

Клиент платит за две части:

1. **Тариф** — набор возможностей кабинета (функциональность).
2. **Каналы** — только те клиенты ВК, которых агентство ведёт сейчас.

Добавил канал → доплата.  
Отключил / отправил в архив → со следующего периода не платит за него.

Так стыкуется с пакетами, которые агентство продаёт своим клиентам:

| Пакет клиенту агентства | Постов / мес |
|-------------------------|--------------|
| Старт | 12 |
| Бизнес | 25 |
| Премиум | 45 (+ упор на видео) |

---

## 2. Тарифы по функциональности

Лимита «максимум N каналов в тарифе» **нет**. Масштаб = число оплаченных каналов.

| | Free | Стандарт | Pro | Agency |
|--|------|----------|-----|--------|
| **Цена тарифа** | 0 ₽ · **14 дней** | **1 490 ₽/мес** | **3 900 ₽/мес** | **9 900 ₽/мес** |
| **Смысл** | полный тест продукта | контент-ведение | контент + **ВК Реклама** | команда / агентство |
| Контент-план, ИИ, генерация | да | да | да | да |
| Согласование, автопубликация | да | да | да | да |
| Отчёты | да | базовый | полный | полный + Excel/PDF |
| **Кабинет ВК Реклама** | демо в триале | нет | **да** | **да, сводка по портфелю** |
| Менеджеры в аккаунте | 1 | 1 | 1 | **до 5** (далее +990 ₽/чел) |
| Приоритет / поддержка | обычная | обычная | выше | приоритет + консультант |

### Ценность апгрейда тарифа

| Переход | За что платят больше |
|---------|----------------------|
| Free → Стандарт | остаться после триала, вести каналы платно |
| Стандарт → Pro | **кабинет ВК Реклама** + сильнее отчёты |
| Pro → Agency | команда менеджеров, сводка по портфелю, приоритет, B2B-сопровождение |

Дороже тариф = **инструменты агентства**, а не «разрешение завести ещё 2 канала».

## 3. Оплата за канал

Каждый активный канал включает пул генераций под пакет клиента:

| Пакет на канале | Постов | Видео / мес | Цена канала для агентства |
|-----------------|--------|-------------|---------------------------|
| **Старт** | 12 | 0 | **690 ₽/мес** |
| **Бизнес** | 25 | 1 | **1 290 ₽/мес** |
| **Премиум** | 45 | 4 | **2 290 ₽/мес** |

В цену канала заложено:

- генерации по лимиту пакета;
- запас на типичные перегенерации;
- контент-план по каналу.

**Докупки сверх пакета канала (ориентир):**

| Докупка | Цена |
|---------|------|
| +10 постов (текст+картинка) | 490 ₽ |
| +1 видео | 190 ₽ |
| +10 перегенераций визуала | 290 ₽ |

### Правила

1. Активный канал = есть в кабинете и не в архиве.
2. Смена пакета канала (25→45) — пересчёт доплаты.
3. Free: до **2 каналов**, полный функционал **14 дней**; после — без оплаты только просмотр.
4. Сверх пакета — докупка, не безлимит.
5. ВК Реклама — с **Pro** (демо можно в триале). Модуль в продукте ещё планируется.

## 4. Примеры счёта агентства

**A. Фрилансер · Стандарт · 2 клиента на Бизнес**  
`1 490 + 2 × 1 290 = **4 070 ₽/мес**`

**B. Pro · 5 клиентов (3 Бизнес + 2 Премиум)**  
`3 900 + 3×1 290 + 2×2 290 = **12 350 ₽/мес**`

**C. Agency · 15 клиентов на Бизнес**  
`9 900 + 15 × 1 290 = **29 250 ₽/мес**`

**D. Agency · 20 клиентов (10 Бизнес + 10 Премиум)**  
`9 900 + 10×1 290 + 10×2 290 = **44 700 ₽/мес**`

Фраза для лендинга:  
«Выберите возможности кабинета. Дальше платите только за тех клиентов ВК, которых ведёте сейчас — пакет Старт, Бизнес или Премиум на каждый канал.»

## 5. Тарифы API (база для себестоимости)

Из системы (`webapp/services/business.py`, значения по умолчанию):

| Операция | Тариф |
|----------|-------|
| Текст поста (Claude) | 3 ₽ |
| Картинка | 8 ₽ |
| Видео (Kling) | 25 ₽ |
| Контент-план | 5 ₽ |
| Бриф ИИ-маркетолога | 5 ₽ |

### Реальная цепочка агентов на 1 пост

| Шаг | Агент | Нам ≈ | В журнале сейчас |
|-----|--------|-------|------------------|
| Веб-поиск | поиск | ~0 ₽ | нет |
| Актуальность | Claude | 3 ₽ | **нет (дырка)** |
| Текст поста | Claude | 3 ₽ | да |
| Промпт визуала (часто 2-й Claude) | Claude | ~3 ₽ × 0.35–0.4 | **нет (дырка)** |
| Картинка | VseGPT→KIE | 8 ₽ | да |
| Видео | Kling | 25 ₽ | да |

**Ориентир на 1 пост:**

| Тип | Наш COGS ≈ |
|-----|------------|
| Текст + картинка (все агенты) | **~15 ₽** |
| Текст + картинка + видео | **~40 ₽** |
| Перегенерация текста | **~6 ₽** |
| Перегенерация визуала | **~10 ₽** |

«Идеальный» учёт только text+image=11 ₽ **занижает** реальную себестоимость примерно на 25–35%.

## 6. Симуляция: онбординг канала (с перегенерациями)

Новичок **не** настраивает канал с первого раза.

### Первый канал (новичок) ≈ **127 ₽**

| Действие | Кликов ИИ | ₽ |
|----------|-----------|---|
| ИИ · описание | 3 | 9 |
| ИИ · база знаний | 3 | 9 |
| ИИ · промпт стиля | 4 | 12 |
| Превью стиля (картинка) | 4 | 32 |
| ИИ-маркетолог · бриф | 3 | 15 |
| ИИ · рубрики (~5 × 2.5) | 12.5 | 37.5 |
| Контент-план (попытки) | 2.5 | 12.5 |

### Следующие каналы (уже умеет) ≈ **64 ₽**

Примерно в 2 раза меньше попыток.

## 7. Себестоимость 1 канала для нас (переменные / API)

С запасом на типичные перегенерации в стабильном режиме:

| Пакет канала | Наш API ≈ | Цена канала | Маржа с канала |
|--------------|-----------|-------------|----------------|
| Старт 12 | **250–350 ₽** | 690 ₽ | ~340–440 ₽ |
| Бизнес 25 | **550–800 ₽** | 1 290 ₽ | ~490–740 ₽ |
| Премиум 45 | **1 200–1 800 ₽** | 2 290 ₽ | ~500–1 000 ₽ |

Плата за **тариф** (1 490 / 3 900 / 9 900) в основном покрывает фикс компании (сервер, люди), а не API.

## 8. Постоянные расходы компании (фикс / мес)

| Статья | Сумма |
|--------|--------|
| Облачный сервер (VPS, БД, бэкапы) | **8 000 ₽** |
| Техспециалист | **120 000 ₽** |
| B2B-консультант (продажи, онбординг) | **80 000 ₽** |
| **Итого фикс** | **208 000 ₽/мес** |

Фикс делится на всех платящих. Чем больше подписчиков на тарифы, тем ниже «полная» себестоимость одного аккаунта.

**Free-триал** нам обычно обходится **~450–900 ₽** на аккаунт (онбординг + генерации) — цена лида.

## 9. Стыковка «агентство продало пакет клиенту» ↔ «мы получили оплату»

Раньше конфликт был в модели «лимит постов на весь кабинет» (например 80 постов при 10 каналах): нельзя нормально продать несколько Бизнес 25 / Премиум 45.

В модели **«функции + канал»**:

- клиенту продали **Бизнес 25** → агентство платит нам **1 290 ₽ за этот канал**;
- клиенту продали **Премиум 45** → **2 290 ₽ за канал**;
- число каналов не ограничено тарифом — ограничено только тем, сколько агентство готово оплатить.

## 10. Типичные сценарии «агентство платит / наша переменная маржа»

Оценка при средней утилизации (не выжимают пул на 100% каждый месяц).

| Сценарий | Что платит агентство | Наш API (ориентир) | Остаток на фикс/прибыль |
|----------|----------------------|--------------------|-------------------------|
| 2 канала Бизнес + Стандарт | ~4 070 ₽ | ~1 200–1 600 ₽ | ~2 500–2 900 ₽ |
| 5 каналов (3 Бизнес + 2 Премиум) + Pro | ~12 350 ₽ | ~4 500–6 500 ₽ | ~5 800–7 800 ₽ |
| 15 каналов Бизнес + Agency | ~29 250 ₽ | ~9 000–12 000 ₽ | ~17 000–20 000 ₽ |
| 20 каналов (10+10 Бизнес/Премиум) + Agency | ~44 700 ₽ | ~18 000–26 000 ₽ | ~19 000–27 000 ₽ |

Точка безубыточности по фиксу ~208 тыс. ₽ зависит от числа платящих аккаунтов и среднего чека. Ориентир: устойчивый плюс при **порядке 80–130 платящих** (микс тарифов и каналов), если контролировать Премиум/видео и докупки.

## 11. Риски и рекомендации

1. **Премиум + много видео** — самый дорогой сегмент для нас; обязательны лимиты видео в пакете канала и докупка сверх.
2. **Журнал ApiUsageLog** сейчас не пишет отдельно актуальность и 2-й Claude на визуал — отчёты занижают COGS; позже лучше добавить `relevance` / `visual_prompt`.
3. **ВК Реклама** пока не реализована — в тарифе Pro/Agency уже заложить, на лендинге можно «в тарифе / в разработке».
4. Не возвращаться к модели «один общий пул постов на 10 каналов» без привязки к 12/25/45 — снова сломается продажа пакетов клиентам агентства.

## 12. Краткая формула продукта

```
Счёт агентства в месяц =
  цена тарифа (Free / Стандарт / Pro / Agency)
  + сумма цен активных каналов (Старт / Бизнес / Премиум)
  + докупки сверх лимитов
```

```
Наша экономика ≈
  (маржа с каналов − API)
  + (выручка с тарифов − доля фикса: сервер + техспец + B2B)
```
