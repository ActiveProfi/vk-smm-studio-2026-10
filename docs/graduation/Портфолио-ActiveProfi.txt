1. Главный проект (выпускной)
────────────────────────────────────────

Название: VK SMM — кабинет агентства для ВКонтакте с ИИ
Ссылка: https://github.com/ActiveProfi/vk-smm
Формат: веб-приложение (Python / Flask)

Задача бизнеса:
SMM-агентствам сложно вести много клиентов ВК без найма:
контент-план, тексты, визуал, согласование, публикация, отчёты.

Что сделано:
• Кабинет с несколькими каналами (клиентами)
• ИИ-генерация плана, текста, картинки и видео
• Согласование плана клиентом по ссылке
• Календарь и публикация / автопубликация в ВК
• Месячный отчёт (Excel / PDF)
• Тарифы + тестовая форма оплаты
• КП со скриншотами и README

Результат:
Рабочий продукт для демонстрации и практического использования,
а не только набор промптов.

Материалы:
• КП: docs/graduation/КП-VK-SMM.html (и PDF)
• Отчёт: docs/graduation/Отчёт-выпускной-VK-SMM.txt
