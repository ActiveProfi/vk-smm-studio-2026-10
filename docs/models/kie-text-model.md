# Текстовая модель KIE для первой версии агента

Этот файл фиксирует, какую текстовую модель мы используем в первой версии агента и как с ней работать.

## Выбранная стартовая модель

- Основная модель: `claude-sonnet-4-6`
- Запасная модель: `claude-opus-4-5`

## Почему выбрана Claude

- Хорошо подходит для длинных осмысленных текстов.
- Удобна для структурированных ответов и сценариев.
- Подходит для задач: пост, разбор, сериал, чек-лист, промпт для визуала.

## Endpoint

- `POST /claude/v1/messages`
- Базовый URL: `https://api.kie.ai`

## Обязательные поля запроса

- `model`
- `messages`

## Полезные поля

- `stream`: для первой версии лучше ставить `false`, чтобы получать обычный ответ.
- `thinkingFlag`: можно включать позже для сложных задач, но для первой версии не обязательно.
- `tools`: не нужны для первой версии агента.

## Рекомендуемый режим для v1

- `model`: `claude-sonnet-4-6`
- `stream`: `false`
- без `tools`
- один системный блок + один user-блок

## Формат messages

Поддерживаются роли:

- `user`
- `assistant`

Для первой версии агента достаточно передавать:

1. системные правила как первый текстовый блок;
2. затем пользовательский запрос с данными из контракта входа.

## Практическое правило для проекта

- Все 4 промпта по типам постов пишем под текстовую генерацию через Claude.
- Промпты должны возвращать:
  - готовый черновик поста;
  - краткое объяснение структуры;
  - рекомендацию `image` или `video`;
  - промпт для KIE-визуала.

## Что важно не забыть

- Claude не должен выдумывать факты по НДС.
- Если данных не хватает, модель должна прямо просить уточнение.
- Для числовых примеров по умолчанию используем только **22%**.
