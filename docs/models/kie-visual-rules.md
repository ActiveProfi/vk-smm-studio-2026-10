# Правила по визуальным моделям KIE

Этот файл нужен, чтобы текстовые промпты и будущий Python-скрипт учитывали реальные параметры визуальных моделей.

## 1. GPT Image 2

Использовать для:

- инфографики;
- чек-листов;
- обложек;
- каруселей;
- комиксов и сериалов в статике.

### Технические параметры

- модель: `gpt-image-2-text-to-image`
- endpoint: `POST /api/v1/jobs/createTask`
- обязательное поле: `input.prompt`
- `prompt`: до `20000` символов
- `aspect_ratio`: можно задавать явно (`4:5`, `1:1`, `16:9`, `9:16` и др.)
- `resolution`: `1K`, `2K`, `4K`

### Рекомендуемые настройки для v1

- `aspect_ratio`: `4:5` для ленты VK, `1:1` для карточек, `16:9` для обложки статьи
- `resolution`: `1K`

### Важное правило для промптов

- Не перегружать картинку длинным русским текстом.
- Лучше просить композицию, персонажей, иконки, цифры и крупные короткие фразы.
- Если нужен длинный текст, его лучше накладывать потом вручную в редакторе.

### Референсный стиль инфографики

Если нужен визуал в духе `NotebookLM`, ориентироваться на такие признаки:

- светлый или белый фон;
- очень крупный заголовок сверху;
- 3-5 смысловых блоков;
- короткие и чистые русские фразы без ошибок;
- иконки, стрелки, шкалы, пороги, предупреждения, простые схемы;
- логика чтения слева направо или сверху вниз;
- текст помогает понять суть, а не просто украшает картинку.

### Практическое правило для русского текста (кириллица)

- Весь смысловой текст на картинке и в кадре видео — **только кириллица** (русский алфавит).
- Каждую короткую фразу для отрисовки писать в кавычках «...» и требовать точного совпадения букв.
- Запрещены: латиница в смысловых надписях, смесь латиницы/кириллицы в одном слове, псевдокириллица, нечитаемые каракули.
- Исключение: маленькая подпись внизу — только если она задана во входных данных канала/формы.
- Шрифт: простой рубленый, крупный, высокий контраст, ровные буквы.
- Лучше 2–5 коротких русских фраз, чем одна длинная «простыня».
- Для экспертных тем по НДС сначала предпочитать инфографику или карточку, а не чистый text-to-video.
- Если русский текст критичен для смысла, сначала собирать статичную инфографику (Image 2), затем при необходимости анимировать кадр (Kling image-to-video), чтобы буквы не «плыли».
- Для первой версии проекта стиль `NotebookLM` считать хорошим ориентиром для:
  - чек-листов;
  - разборов;
  - карточек с порогами, ставками, рисками и шагами.

### Легкая фирменность

Если инфографика должна оставаться светлой и чистой, но при этом быть чуть более узнаваемой для бренда, добавлять только мягкие элементы:

- жёлтый акцент на ключевом числе, стрелке, линии или иконке;
- тонкую тёмно-синюю или графитовую линию-разделитель;
- 1-2 динамичных диагональных штриха или дорожки в духе гоночной темы;
- маленькая подпись внизу — только если задана во входных данных;
- общий аккуратный контраст: светлый фон + тёмный текст + жёлтые акценты.

Важно:

- не превращать светлую инфографику в тёмный баннер;
- не перегружать дизайн бренд-элементами;
- бренд должен читаться как лёгкий акцент, а не как декор ради декора.
- Не добавляй чужой сайт или домен. Подпись внизу — только из входных данных пользователя.

## 2. Veo 3.1

Использовать для:

- коротких вертикальных видео;
- анонсов;
- эмоциональных роликов;
- коротких объяснений 10–30 секунд.

### Технические параметры

- endpoint: `POST /api/v1/veo/generate`
- модели:
  - `veo3`
  - `veo3_fast`
  - `veo3_lite`
- обязательное поле: `prompt`

### Режимы генерации Veo

- `TEXT_2_VIDEO` — если создаём ролик только по тексту
- `FIRST_AND_LAST_FRAMES_2_VIDEO` — если есть стартовый и финальный кадр
- `REFERENCE_2_VIDEO` — если есть референсы; для этого режима нужен `veo3_fast`

### Форматы VK для Veo

- `aspect_ratio`: `9:16` для клипов
- вертикаль задавать явно, не оставлять `Auto`

### Настройки Veo для v1

- модель: `veo3_fast`
- `aspect_ratio`: `9:16`
- `generationType`: `TEXT_2_VIDEO`, если работаем без референсов
- `enableTranslation`: `true`
- `stream` здесь не используется, это не chat endpoint

### Правило промптов для Veo

- Сначала утверждаем текст и сценарий ролика.
- В видео-промпте описываем:
  - сцену;
  - движение;
  - эмоцию;
  - длительность;
  - формат кадра.
- Не просим длинные юридические формулировки прямо внутри видео.

## 3. Hailuo

Использовать для:

- image-to-video от заранее подготовленного кадра;
- роликов, где важен стартовый визуал;
- случаев, когда текст в кадре лучше сначала собрать на картинке.

### Технические параметры Hailuo

- endpoint: `POST /api/v1/jobs/createTask`
- text-to-video модель: `hailuo/02-text-to-video-pro`
- image-to-video модель: `hailuo/02-image-to-video-pro`
- статус задачи: `GET /api/v1/jobs/recordInfo?taskId=...`

### Практическое правило Hailuo

- Если в ролике нужен русский текст внутри кадра, безопаснее сначала сделать кадр через `GPT Image 2`, потом анимировать через `Hailuo`.
- Для первой версии проекта `Hailuo` считать хорошей альтернативой `Veo`, когда нужен маршрут `image-to-video`.

## 4. Kling 3.0

Использовать для:

- более постановочных коротких роликов;
- image-to-video от готового кадра;
- вертикальных роликов `9:16`, где нужна более управляемая анимация.

### Технические параметры Kling

- endpoint: `POST /api/v1/jobs/createTask`
- модель: `kling-3.0/video`
- статус задачи: `GET /api/v1/jobs/recordInfo?taskId=...`
- для v1 использовать:
  - `mode`: `pro`
  - `multi_shots`: `false`
  - `aspect_ratio`: `9:16`

### Практическое правило Kling

- Если текст должен быть внутри самого видео, сначала делаем картинку через `GPT Image 2`, потом подаём её в `Kling 3.0`.
- Если нужна быстрая тестовая версия без текста в кадре, можно использовать и прямой single-shot prompt.

## 5. Общее правило выбора модели

- `GPT Image 2` — если нужен статичный визуал с фактами, структурой, инфографикой.
- `Veo 3.1` — если нужен короткий живой ролик без критически важного текста в кадре.
- `Hailuo` — если нужен управляемый маршрут `image-to-video`.
- `Kling 3.0` — если нужен более постановочный короткий ролик или анимация готового кадра.

Отдельно:

- для русскоязычной инфографики с несколькими смысловыми блоками сначала выбирать `GPT Image 2`;
- затем уже решать, нужно ли оживлять её через `Hailuo` или `Kling 3.0`.

## 6. Что учитывать в 4 текстовых промптах

Каждый текстовый промпт должен уметь возвращать не только пост, но и:

1. рекомендацию `image` или `video`;
2. для `video` — рекомендованную видеомодель;
3. короткий промпт для `GPT Image 2`, `Veo 3.1`, `Hailuo` или `Kling 3.0`;
4. формат под VK;
5. если в кадре нужен текст — отдельно:
   - image prompt для `GPT Image 2`;
   - video prompt для анимации этой картинки.
