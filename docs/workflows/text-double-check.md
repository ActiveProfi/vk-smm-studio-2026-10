# Двойная проверка текста перед выдачей

Этот алгоритм обязателен для всех текстов агента перед тем, как показывать пользователю итоговый черновик поста.

## Этап 1. Проверка на факты

Агент обязан проверить:

1. Все цифры, ставки и формулировки по НДС сверены с `knowledge/nds-2026-facts.md`.
2. В тексте нет выдуманных норм, сроков, лимитов и обещаний результата.
3. Если в исходных материалах не хватает данных, агент не додумывает, а пишет, что нужно уточнить.
4. В числовых примерах по умолчанию используется только ставка **22%**, если пользователь явно не дал другой сценарий.
5. Упоминания ставок **10%**, **0%**, **5%**, **7%** идут только с кратким пояснением контекста.

Если хотя бы один пункт не пройден, агент не должен выдавать текст как готовый.

## Этап 2. Проверка на соответствие VK

После фактчека агент обязан проверить:

1. Текст понятен бухгалтеру и предпринимателю, без перегруза канцеляритом.
2. Сложная мысль объяснена простым языком даже для новичка.
3. Объём подходит для VK: ориентир до **4000 символов**.
4. В тексте есть логичный хук, структура и читаемые абзацы.
5. Текст оформлен с учётом UX: короткие абзацы, пустые строки между блоками; **главный заголовок** и **подзаголовки/названия блоков** — отдельными строками в формате `**...**`; без `#`, обратных кавычек и `---`.
6. Текст готов к простому копированию в VK: нет служебных пометок и символов разметки.
7. В конце есть вопрос, мягкий CTA или понятное завершение по формату рубрики.
8. Нет длинных перегруженных блоков, которые тяжело читать в ленте.
9. Если текст экспертный или длинный, есть короткая оговорка, что материал не заменяет индивидуальную консультацию.

## Финальное правило выдачи

Перед финальным ответом агент делает внутреннюю последовательность:

1. `Фактчек`
2. `Проверка на VK-формат`
3. `Только потом финальный черновик`

## Что показывать пользователю

Если обе проверки пройдены, агент выдаёт:

1. Черновик поста
2. Почему формат выбран правильно
3. Рекомендацию по визуалу
4. Промпт для KIE
5. Что проверить перед публикацией

Если проверка не пройдена, агент сначала сообщает, что именно надо уточнить или исправить.
