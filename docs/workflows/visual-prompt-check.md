# Проверка визуального промпта перед генерацией

Этот алгоритм обязателен перед отправкой `image`-промпта в `GPT Image 2`.

## Цель

Картинка не должна содержать:

- спорные юридические утверждения;
- обещания результата;
- категоричные фразы, которые выглядят как налоговая консультация;
- длинный текст, который лучше оставить в посте, а не на изображении.
- иностранные слова, латиницу, англоязычные подписи и служебные слова в смысловом тексте визуала;
- названия платформ и сервисов в смысловом тексте визуала (`VK`, `ВКонтакте`, `Telegram`, `LinkedIn`, `NotebookLM` и другие);
- изображения иностранной валюты, знаки `$`, `€`, `£`, монеты/купюры не из российского контекста;
- лишние декоративные значки, эмодзи, логотипы, биржевые/крипто-символы, знак процента и математические формульные символы, которые могут увести смысл в сторону.

## Этап 1. Проверка на рискованные формулировки

Перед генерацией изображения агент обязан остановить промпт, если в тексте для картинки есть:

- `вычет есть`
- `вычет ограничен`
- `вычет входящего НДС`
- `вычет НДС`
- `НДС — НЕТ`
- `без штрафов`
- `гарантия`
- `точно выгоднее`
- `всегда выгодно`
- `плати меньше`
- `налог будет меньше`
- иностранные слова или латиница в смысловом тексте картинки, кроме обязательной подписи `подпись из входных данных` внизу;
- URL сайта или любые адреса латиницей, кроме обязательной подписи `подпись из входных данных` внизу;
- изображения валюты или знаки валют, включая `$`, `€`, `£`, `₽`;
- знак процента `%`, математические знаки `×`, `−`, `÷`, `=`, `+`, формульные записи вроде `22/122`;
- лишние значки, эмодзи, логотипы, крипто-символы, биржевые символы.

Такие формулировки нельзя автоматически публиковать на картинке без ручной правки.

## Этап 2. Проверка на длину и перегруз

Агент должен считать промпт небезопасным для картинки, если:

1. Внутри изображения предлагаются длинные русские фразы вместо коротких подписей.
2. В картинке пытаются разместить юридическую логику, которую лучше оставить в самом посте.
3. На изображение выносится спорный вывод вместо нейтрального заголовка.
4. В смысловых блоках картинки есть иностранные слова, латиница, иностранная валюта или лишние значки.

## Что разрешено на картинке

Безопасные варианты:

- короткий вопрос;
- короткое сравнение;
- нейтральный заголовок;
- цифры, ставки словами, простые линии и стрелки без декоративных значков;
- формулировки без обещаний и выводов.

Дополнительное строгое правило проекта: для VK-визуалов смысловой текст должен быть только на русском языке. Нельзя добавлять иностранные слова, латиницу, сторонние URL, домены, валютные знаки, знак процента, математические формульные знаки, логотипы, эмодзи и посторонние значки в заголовки, блоки, подписи и схемы.

Исключение: `подпись из входных данных` всегда должен быть маленькой фирменной подписью в самом низу визуала строго по центру. Это не часть смысловой инфографики, а адрес сайта проекта.

Если нужны суммы, писать словами: `рублей`. Если нужны ставки, писать словами: `22 процента`, `5 процентов`, `7 процентов`, без знака `%`. Расчёт на картинке показывать словами: `умножить`, `разделить`, `получается`, без символов `×`, `−`, `÷`, `=`, `+` и без записей вроде `22/122`. Стрелки можно использовать как графические линии, но не как символы `→`, `←`, `↔` внутри текстовых подписей.

Не использовать в image-промпте служебные названия стилей и сервисов вроде `NotebookLM`. Вместо этого писать по-русски: `светлая аналитическая инфографика`.

## Размеры для VK

Для обычной картинки к посту VK промпт обязан явно задавать формат через техническую строку `Aspect ratio`:

1. `4:5` — основной формат для ленты VK.
2. `1:1` — карточка, инфографика, комикс или квадратная иллюстрация.
3. `9:16` — вертикальное видео или базовый кадр для вертикального видео.
4. `16:9` — не использовать для обычного поста, если это не обложка статьи.

Для обложки статьи VK промпт обязан явно задавать горизонтальный формат:

1. Размер: `1020x572 px`.
2. Соотношение сторон: `16:9`.
3. Ориентир VK: минимально `510x286 px`, лучше генерировать в двойном размере `1020x572 px`.
4. Важный текст держать в безопасной зоне: не ближе примерно одной десятой ширины от краёв.
5. Не писать в промпте `квадратная обложка`, `1:1`, `постер`, `вертикальный формат`, если речь именно об обложке статьи.

Для запуска генерации обложки статьи через KIE использовать:

```powershell
py -3 tools/generate_kie_image_from_prompt.py --prompt-file "<prompt.txt>" --out-json "<result.json>" --out-link "<link.txt>" --aspect-ratio 16:9
```

Примеры:

- `22 процента или 5 процентов?`
- `Считать надо глубже`
- `Сравнивайте не только ставку`
- `Выбор ставки НДС`
- `НДС: считайте всю нагрузку`

## Финальное правило

Если визуальный промпт не проходит проверку:

1. Агент не отправляет его в `GPT Image 2`.
2. Агент сообщает, какие именно фразы опасны.
3. Агент предлагает сделать изображение более нейтральным.
