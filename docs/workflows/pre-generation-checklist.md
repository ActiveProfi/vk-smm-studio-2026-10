# Обязательный pre-check перед любой генерацией

Этот чек-лист обязателен перед каждым запуском генерации текста, изображения или видео.

## Шаг 1. Проверка правил проекта

Перед началом агент обязан сверить:

1. `.cursor/rules/vk-kie-agent.mdc`
2. `prompts/base-system-kie.md`
3. профильный промпт рубрики из `prompts/*.md`
4. для image: `docs/workflows/visual-prompt-check.md`

## Шаг 2. Фирменная подпись на визуале

Для любого визуала обязательно:

1. подпись `подпись из входных данных` должна быть в самом низу;
2. подпись должна быть строго по центру нижней зоны;
3. подпись маленькая и аккуратная, без конкуренции с главным заголовком.

## Шаг 3. Запрет посторонних названий в тексте изображения

В видимом смысловом тексте визуала запрещены:

1. названия платформ и сервисов: `VK`, `ВКонтакте`, `Telegram`, `LinkedIn`, `YouTube`, `Instagram`, `NotebookLM` и аналоги;
2. сторонние бренды, домены и адреса;
3. любая латиница, кроме фирменной подписи `подпись из входных данных`.

## Шаг 4. Финальная проверка перед запуском

Перед генерацией агент обязан проверить и подтвердить:

1. соответствует ли визуал типу рубрики;
2. нет ли переноса визуальной логики из другой рубрики;
3. есть ли `подпись из входных данных` внизу по центру;
4. нет ли посторонних названий в смысловом тексте.
