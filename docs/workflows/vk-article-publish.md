# Публикация статьи VK и обложки

Этот регламент фиксирует шаги для публикации полноценной статьи VK с обложкой.

Отдельно от обычного поста на стене: пост публикуется через `publish_vk_playwright_strict.py`, а статья пока готовится и проверяется как отдельный материал.

## Шаг 1. Подготовить материалы

Для каждой темы должны быть готовы:

1. Файл статьи в `Итоговые результаты/<ТЕМА>/`.
2. Файл поста-анонса для VK.
3. Обложка статьи.
4. Иллюстрация поста.
5. Ссылки на итоговые визуалы, если они сгенерированы через KIE.

Для новых PNG, JPG, WEBP и MP4 в `Итоговые результаты` обязательно добавлять в имя файла суффикс нейросети:

- суффикс `Nano Banana Pro` для обложек, иллюстраций, инфографики и статичных картинок.
- суффикс `Hailuo`, `Kling` или `Veo` для видео.

## Шаг 2. Проверить текст статьи

Перед публикацией статьи агент обязан проверить:

1. Факты по НДС сверены с `knowledge/nds-2026-facts.md`.
2. Нет выдуманных сроков, лимитов, норм и обещаний результата.
3. Есть понятная структура: заголовок, вводный блок, смысловые разделы, вывод.
4. Если текст юридически или налогово значимый, есть оговорка: материал носит просветительский характер и не заменяет индивидуальную консультацию.

Для проверки использовать правило:

`docs/workflows/text-double-check.md`

## Шаг 3. Проверить обложку статьи

Перед генерацией или публикацией обложки проверить промпт по правилу:

`docs/workflows/visual-prompt-check.md`

Обложка статьи должна быть:

1. В стиле понятной инфографики.
2. Горизонтальной, под размер VK-статьи: `1020x572 px`, соотношение `16:9`.
3. С крупным русским заголовком.
4. С 3-5 смысловыми блоками.
5. С безопасными отступами: важный текст не ближе 8-10% от краёв.
6. Без иностранных слов, латиницы, логотипов, эмодзи, иностранных валют и лишних декоративных значков в смысловых блоках.
7. С маленькой фирменной подписью `подпись из входных данных` в самом низу обложки.
8. Без обещаний результата и спорных юридических выводов.

Для генерации обложки статьи через KIE обязательно указывать:

```powershell
py -3 tools/generate_kie_image_from_prompt.py --prompt-file "<prompt.txt>" --out-json "<result.json>" --out-link "<link.txt>" --aspect-ratio 16:9
```

Если обложка не одобрена, старый вариант удалить. В `Итоговые результаты` хранить только актуальные утверждённые файлы и ссылку на них. Технические `result.json`, временные скриншоты, диагностические файлы и неудачные версии туда не складывать и не оставлять.

## Шаг 4. Создать статью в VK

Пока статья публикуется через интерфейс VK вручную или полуавтоматически.

1. Открыть страницу стены сообщества:

   `https://vk.com/wall-227844577?own=1`

2. Нажать кнопку `Статья`.
3. Вставить заголовок статьи.
4. Вставить текст статьи.
5. Загрузить обложку статьи.
6. Проверить, что обложка отображается именно как обложка статьи, а не как обычная картинка в тексте.
7. Проверить переносы, подзаголовки и читаемость.
8. Сохранить статью как черновик или опубликовать после одобрения.

## Шаг 5. Зафиксировать ссылку на статью

После публикации статьи нужно сохранить ссылку:

1. В файл темы в `Итоговые результаты/<ТЕМА>/`.
2. В Supabase в запись `vk_drafts`, если статья связана с постом-анонсом.
3. В поле `output_files`, например:

```json
{
  "vk_article_url": "https://vk.com/@...",
  "article_cover_url": "https://...",
  "article_publish_mode": "manual_vk_editor"
}
```

Секреты, токены и ключи в эти файлы не записывать.

## Шаг 6. Связать статью с постом-анонсом

Если на стене публикуется пост-анонс, в нём должна быть понятная связка со статьёй:

1. Короткий хук из темы статьи.
2. 3-5 ключевых тезисов.
3. Ссылка на статью или фраза `Ссылка на полную статью — в комментарии`, если так удобнее для VK.
4. Иллюстрация поста, не обложка статьи.

Обычный пост-анонс публикуется через:

```powershell
py -3 publish_vk_playwright_strict.py --publish --draft-id <ID_ЧЕРНОВИКА>
```

## Шаг 7. Финальная проверка после публикации

После публикации проверить:

1. Статья открывается по ссылке.
2. Обложка видна и не обрезана критично.
3. В статье нет технических комментариев, промптов, служебных заголовков и лишних символов.
4. В посте-анонсе есть иллюстрация.
5. В Supabase статус и ссылки обновлены.

Для текущей темы `НДС - коды видов операций` связанный пост на стене:

`https://vk.com/wall-227844577_52`
